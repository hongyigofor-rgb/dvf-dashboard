# DVF-PRO 戰情室（雲端自動更新版）

GitHub Actions 在台股交易日自動執行，手機或平板打開 GitHub Pages 永遠是最新資料，不需要 Mac 開機。

| 時間（台北） | 工作 |
|---|---|
| 09:00–13:55 每 5 分鐘 | 抓證交所 MIS 即時報價、重算盤中動態檢討、重新部署 |
| 15:20（17:30 補跑） | 完整盤後掃描（TWSE／TPEx、FinMind、期貨、集保、新聞）並保存到 `state` 分支 |
| 推送程式到 main | 立即重新部署 |

- 網頁內容在部署前會遮蔽持股成本、目標價、停損與 AI 覆盤；AI 覆盤與 Email 只在作者本機執行。
- `state` 分支只保存最新一份掃描結果與 TDCC 集保週資料，每次強制覆寫、不累積歷史。
- GitHub 排程在尖峰時段可能延遲數分鐘，盤中更新頻率約 5～15 分鐘。
- 本 repo 的程式由作者本機 `sync_cloud.py` 同步，請勿直接在 GitHub 上修改。
- 選填 Secrets：`FINMIND_TOKEN`、`CORE_POSITIONS`（代號:目標價:成本，網頁上會遮蔽）。

本工具為量化篩選與盤中參考訊號，不構成投資建議。
